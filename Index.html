PACMUSCLE

頭を伸ばし噛みついて破壊、噛みついて移動ができるアクションゲーム

  • 概要: CSVでタイルID（整数）を管理し、Unity上で「編集→保存/読込→プレハブ自動配置」までを一気通貫で行う軽量マップ制作ツール
  • 開発環境: Unity（C# / Editor拡張）, Visual Studio / VS Code
  • 制作期間: 3日間
  • 人数: 6人
  • 担当: エディタUI（EditorWindow/2Dグリッド）, CSV入出力, プレハブ自動生成/再生成
  • PAC 説明動画: https://youtu.be/HRUxui_WSPI

主な機能

  • サムネイルからタイル（プレハブ）を選択し、クリックで配置／右クリックで消去
  • grid[x,y] をCSVとして保存・読み込み（テキスト管理しやすく差分が追いやすい）
  • CSV内容からプレハブを自動生成し、親オブジェクト配下にまとめて配置

工夫点

  • タイルID⇔プレハブ対応をScriptableObject（CSVMapPrefabSetting）に外出しして、コード変更なしで差し替え・追加が可能
  • 再生成時は古い生成物を削除し、二重生成やゴミ残りを防止
  • Orthographic Cameraの表示範囲からcellSizeを算出し、マップ全体が画面に収まるよう自動調整
